# slimefinder-scripts-mPack
查找全区块史莱姆农场配置化脚本

核心jar包原仓库[slimefinder](https://github.com/Nukelawe/slimefinder)

脚本作者[MapleDust](https://github.com/MapleDust)

## 使用例程

### start.bat

用于一键启动程序，在弹出的cmd窗口中输入数字1-3可以直接执行对应模式

- 各数值对应模式如下：

1.搜索史莱姆区块 

2.从文件生成区块分布图 

3.取消并退出

### mask.properties

需要在这里设定使用的世界种子才能搜索史莱姆区块

### search.properties

配置搜索的范围、输出文件的模式、挂机点等

### image.properties

从给定或已搜索出的史莱姆区块数据生成区块分布图
